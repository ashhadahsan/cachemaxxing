Stop paying full price for the same tokens.

Anthropic, OpenAI and Gemini bill a repeated prompt prefix at a fraction of the input price, but only when the bytes really repeat. cachemaxxing measures your hit rate, finds the byte where your prompts stop repeating, and lays them out so they do.

Get started
$pip install cachemaxxing
chat.py
from cachemaxxing import Prompt, usage

chat = [{"role": "system", "content": SYSTEM},          # long, fixed instructions
        {"role": "user", "content": "How do I reset my router?"}]

p = Prompt("support.answer").messages(chat)          # same list you already keep
resp = client.chat.completions.create(**p.openai_chat("gpt-6-luna"))
print(f"{usage(resp).hit_rate:.0%} from cache")

A cache miss never raises an error. The bill is just higher.

The only ground truth is the usage the provider sends back. cachemaxxing starts there.

Measure

usage() turns any provider's response into the same numbers: input, cache read and write, output, hit rate, $ spent and $ saved.

$ cachemaxxing report calls.jsonl --min-hit-rate 0.6
call site     calls  hit rate  est $   saved $
rag.answer    5      71.7%     0.0034  0.0024
support.chat  6      82.8%     0.0017  0.0028

Diagnose

cachemaxxing diff shows the first byte where two requests stop matching, and names the likely cause: a timestamp, an id, tool order or JSON key order.

$ cachemaxxing diff request_1.json request_2.json
diverges at system[0].text char 41 (timestamp), after ~14 matching tokens
  a: 'You are helpful. Today is 2026-10-30T10:00:00Z.'
  b: 'You are helpful. Today is 2026-10-30T10:05:00Z.'

Fix

Prompt puts the stable parts first and places each provider's cache markers: on the system prompt, and on the conversation so far.

p = Prompt("rag.answer")
p.system(SYSTEM).history(chat)
p.retrieved(chunks).user(question)
kw = p.anthropic("claude-haiku-5-5")

Measured, including where it matters less

Same content in three layouts: a typical app, a clean prompt with the provider's own automatic caching, and cachemaxxing.

  • Against a typical app: 76–88% cheaper

    Input cost for chat and RAG, on every model. The usual culprits are a timestamp in the system prompt, shuffled tools and re-rendered history.

  • Anthropic: 82–89% cheaper than automatic caching

    Automatic caching puts its one cache entry after the per-turn context, so every call pays the write premium and reads nothing back.

  • Gemini: 62–67% cheaper

    Implicit caching is best-effort. An explicit cache, created only when it pays, read 88–97% of the input.

  • OpenAI: 6–19% cheaper

    OpenAI's implicit caching already finds a stable prefix. The win there is fixing the habits, plus the measurements.
